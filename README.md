# 📦 Program Hitung Bangun Ruang dan Bangun Datar

Program berbasis C++ untuk menghitung luas dan keliling bangun datar, dan juga luas dan volume bangun ruang.

## 🚀 Fitur Utama

- **Hitung Bangun Datar:** Menghitung luas dan keliling dari bangun datar persegi, persegi panjang, segitiga, dan lingkaran.
- **Hitung Bangun Ruang:** Menghitung luas dan volume dari bangun ruang kubus, balok, tabung, bola.

## 🛠️ Prasyarat

Sebelum menjalankan program ini, pastikan sistem kamu sudah terpasang:

- **Compiler C++** (GCC / MinGW v11.0+)
- **Terminal / Command Prompt** (Windows)

## Cara Menginstal dan Menjalankan

1. **Clone repository ini:**
    ```bash
    git clone [https://github.com/AmmarLabs/plane-figure-and-geometrical-calculator] (https://github.com/AmmarLabs/plane-figure-and-geometrical-calculator)
    cd plane-figure-and-geometrical-calculator
2. **Kompilasi kode program**
    `g++ main.cpp`
3. **Jalankan program:**
    `./a`
